# 版本记录

## 未发布

- 新增 `start/start.vbs` / `start/start.pyw` 双击启动：由 `pythonw.exe` 静默运行，不出现任何控制台窗口，也不依赖 `.pyw` 文件关联；后台运行本机控制台，自动打开链接并通过 URL 片段自动加载本次凭据，仅在启动失败时弹窗提示。
- 页面右上角新增“停止服务”，可结束静默运行的 Web 服务；弹窗可选择同时停止所有已托管任务的后台监控进程（只取消未来续跑，不强制中断 App 中正在执行的任务）。
- Windows 下监控进程派生的 PowerShell、`codex.exe` 和 `cmd.exe` 子进程改为隐藏窗口，不再闪烁命令行窗口。
- Windows 默认路径嗅探支持 Microsoft Store 版本按哈希目录放置的 `codex.exe`。
- 修复 Windows 中文区域读取本地对话时的 GBK 编码错误（标题或预览中的不换行空格等字符）；CLI JSON 输出、错误输出和 watcher 日志统一使用 UTF-8。
- 监控记录中已停止的任务新增“重新启动”按钮：确认一次后重新只读核验实时状态并按填写的累计上限开启监控，不需要重走检查任务流程。
- 续跑内容改为页面配置项：输入框以原有安全文本为 placeholder 和默认值，可随任务保存并在重新启动时修改；命令行可通过 `--continuation` 设置，长度上限 2000 字符。发送前仍重新核验实时状态、落盘意图并执行预算/取消检查。
- 启动入口统一移动到 `start/`；中文说明、发布计划与变更记录移动到 `docs/`。

## 0.2.0 — 源码精简版（2026-08-29）

- 发布方式统一为 GitHub 源码拉取和本机手动启动。
- README 增加完整的下载、启动、界面操作、配置、更新和安全边界说明。
- 仓库只保留 Python 核心、CLI、本机 Web UI、Codex Skill 和对应测试。
- 删除原生 macOS 客户端、小程序、移动端联调、打包签名代码及 npm 依赖。
- Web 控制台固定监听本机回环地址，不再提供跨设备入口。
- 真实额度耗尽跨自然重置周期仍待端到端验证。
